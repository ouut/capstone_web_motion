## 项目目标

**用 MediaPipe 手势追踪驱动 3D 游戏中的光剑**，支持两种模式：

---

## 输入数据

来自 MediaPipe 的 **2D 归一化坐标** (0-1)，分为两种模式：

| 模式 | 左手输入 | 右手输入 |
|------|---------|---------|
| **手部光剑** | 左手腕 + 左手食指指尖 | 右手腕 + 右手食指指尖 |
| **身体光剑** | 左肘部 + 左手腕 | 右肘部 + 右手腕 |

共 **4 个坐标点**（左右各 2 个）。

---

## 核心问题与解决方案

### 问题
MediaPipe 的 Z 轴深度信息**基本不可用**（单目摄像头无法准确获取深度）。

### 解决方案
**2D 坐标 + IK 约束重建 3D**，核心思路：

1. **用 2D 像素坐标计算射线方向**（准确且稳定）
2. **用已知的物理长度约束**求解 3D 位置（手臂长度 / 前臂长度）
3. **加入"剑柄永远比剑头更靠近身体"约束**，消除多解性，减少抖动

---

## 两种模式的唯一区别

| | 手部光剑 | 身体光剑 |
|------|---------|---------|
| **起点** | 手腕 | 肘部 |
| **终点** | 食指指尖 | 手腕 |
| **约束长度** | 手腕到食指（约 18cm） | 前臂长度（约 29cm） |

**其余逻辑完全一致**：同样的 IK 求解、同样的方向约束、同样的平滑处理。

---

## 输出格式

每个光剑输出：

```javascript
{
  position: [x, y, z],      // 3D 位置（剑柄坐标）
  rotation: [x, y, z, w],   // 四元数旋转
  direction: [x, y, z]      // 光剑指向（剑柄→剑尖）
}
```

左右手各一个，共两个光剑的姿态数据。

---

## 关键约束

1. **长度约束**：手腕/肘部在 3D 空间中的位置受物理长度限制
2. **方向约束**：光剑必须指向远离身体的方向（剑柄比剑头更靠近身体）
3. **时间平滑**：消除抖动，防止方向突变

---

## 最终形态

一个纯 JavaScript 类 `LightsaberTracker`，接收 4 个 2D 坐标，输出两个光剑的完整 3D 姿态，可直接发送给 Unity/Unreal 等游戏引擎使用。
